# Django HW: Сотрудники и Рабочие места

Это домашнее задание по курсу "Введение в Django". Проект реализует структуру для хранения информации о сотрудниках и их рабочих местах.

## Структура проекта
- `employees` — приложение для работы с данными сотрудников.
- `workplaces` — приложение для работы с данными рабочих мест.
- `mysite` — настройки проекта (settings, urls).

## Как запустить проект

1. **Активируйте виртуальное окружение:**
   - Windows: `venv\Scripts\activate`
   - macOS/Linux: `source venv/bin/activate`

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
